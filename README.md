# 🎯 Quiz Game

This is a simple web-based quiz game that I created as a mini project to practice HTML, CSS, and JavaScript.

The user can answer multiple-choice questions, get instant feedback, and see the final score at the end of the quiz.

## Features

- Multiple-choice quiz questions
- 15-second timer for each question
- Correct and wrong answer indication
- Progress bar
- Automatic next question
- Score and percentage calculation
- Result screen
- Play Again option
- Works on both desktop and mobile screens

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Click **Start Quiz** and begin the quiz.
